# Sistema de asistencia web con Supabase

Version resubida del proyecto original unicamente para realizar pruebas locales con Supabase y despliegue web en vercel.
Creditos: https://github.com/Yeremyyy/Proyecto-MVP-COntrol-de-asistencias

> Proyecto académico.

## Tecnologías
 
| Capa | Tecnología |
|---|---|
| Interfaz | HTML, CSS y JavaScript |
| Compilación | [Vite](https://vite.dev) |
| Base de datos | PostgreSQL en [Supabase](https://supabase.com) |
| Lectura y generación de QR | `html5-qrcode`, `qrcode` |
| Cliente de base de datos | `@supabase/supabase-js` |
| Despliegue | [Vercel](https://vercel.com) |
